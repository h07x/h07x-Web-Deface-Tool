# Installation

# Termux

pkg update && pkg upgrade -y
pkg install git python -y
git clone https://github.com/h07x/h07x-Web-Deface-Tool.git
cd h07x-Web-Deface-Tool
python "Web Deface Tool.py"

- Python 3
